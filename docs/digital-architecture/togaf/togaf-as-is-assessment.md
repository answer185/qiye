# TOGAF-现状梳理

## 背景
在企业数字化转型过程中，现状梳理是架构设计的重要基础工作。

对于制造业企业而言，随着业务规模扩大、生产模式复杂化以及经营管理要求不断提高，企业原有的业务流程、管理模式和信息化系统可能逐渐无法满足发展需求。

常见的问题包括：
- 业务层面： 销售、采购、生产、仓储等业务环节相互割裂，业务流程不够规范，部门之间存在信息壁垒。
- 管理层面： 企业依赖人工经验进行管理，缺乏统一的管理制度、标准和规范，经营决策缺少数据支撑。
IT层面： 各部门独立建设信息系统，系统之间缺乏有效集成，形成信息孤岛。

技术层面： 基础设施老旧，系统架构缺乏统一规划，技术标准不一致，难以支撑未来业务发展。

因此，在开展数字化转型之前，需要先对企业当前的经营管理、业务流程、组织架构、IT系统及技术基础设施进行全面调研。

通过现状梳理，建立企业当前的架构基线（Baseline Architecture），识别业务与IT之间的差距，为后续目标架构设计（Target Architecture）和转型规划提供依据。


## 现状诊断
现状诊断主要从整体、业务、IT、技术和管理五个维度展开。

### 整体现状
了解企业的发展情况、业务规模、组织模式以及当前数字化建设水平。如理解以下内容：
- 工厂创建时间有多久
- 多少人，组织机构是什么样的
- 几条生产线，几个车间，占地面积之类
- 做什么产品
- 年销售额多少，如何变化
- 用了哪些系统：ERP + MES + WMS + OA + 财务系统
- 系统之间有没有使用大量Excel

这部分就是了解企业的过去，为什么要做这个企业，优势在哪。

### 业务现状
业务架构是现状诊断的重点。

需要从企业核心价值链出发，梳理各业务领域、业务流程、业务角色以及业务之间的协作关系。

常见的领域有：
-  采购 
-  销售 
-  订单 
-  计划 
-  生产 
-  仓储 
-  品质 
-  财务
-  人力 
-  研发 

### IT现状
IT现状主要关注企业当前的信息系统建设情况，以及当前IT系统如何支撑业务。

常见的系统或服务有：
-  ERP 
-  MES 
-  WMS 
-  CRM 
-  PLM 
-  OA 
-  BI 
-  HR 
-  财务 
-  IoT 
-  数据平台

### 技术现状
技术现状主要关注企业IT基础设施、技术架构及运行保障能力。

即系统如何在这些设施上运行。包含的内容有：
-  服务器 
-  网络 
-  云 
-  数据库 
-  API 
-  集成 
-  权限 
-  安全 
-  备份 
-  灾备 

### 管理现状
管理现状主要关注企业的组织管理机制、制度规范、数字化治理及IT管理能力。

不仅仅是IT团队的管理，还有企业整体的管理机制。比如：
-  IT团队 
-  IT预算 
-  供应商 
-  项目 
-  SLA 
-  IT制度

## 开展方案
### 大原则
**先了解事实，再做专业判断**

即：不要马上就想着去改系统，提方案，引热门技术之类。应该先弄按把上面各方面的现状了解清楚后再开展。

可以按以下6步走：
### 拿资料
最简单有效的方式是看企业现在沉淀的文档，比如：
-  公司组织架构 
-  部门职责 
-  公司现有系统清单 
-  IT 资产清单 
-  ERP/MES/WMS/OA/财务等系统 
-  现有项目 
-  IT 部门人员 
-  IT 预算 
-  系统供应商 
-  网络架构 
-  服务器情况 
-  数据库情况 
-  公司制度 
-  业务流程文档 
-  报表 
-  KPI 
-  已经提出过的问题 
-  历史 IT 项目方案 
-  系统采购合同 
但是要注意并不是把文档看完再开始工作，而是：
> 一边收资料，一边建立自己的“现状地图”。

### 组织结构梳理
企业的问题，表面上可能是系统问题。但是实际上可能是：组织问题 / 权责问题 / 流程问题 / 数据口径问题。

所以需要先知道谁负责什么？相应的问题应该找谁了解交流。

### 确定“访谈对象”
制造业经常会有很多人，不可能每个人都聊，所以需要先根据资料及组织结构，确定需要访谈的人。可以建立一个：
> 关键干系人访谈矩阵
后续工作也需要继续维护这个矩阵，方便有相应问题时，找到对应的人。如：

| 对象 | 目的 | 重点 |
| --------- | ------------- | -------------- |
|老板/总经理|企业战略|战略、目标、痛点|
|CFO|经营管理|财务、成本、利润|
|销售负责人|客户业务|销售、订单|
|采购负责人|供应链|采购、供应商|
|生产负责人|制造|计划、生产|
|仓储负责人|库存|入库、出库|
|人事负责人|组织|人员、组织|
|IT负责人|IT|系统、基础设施|
|一线员工|实际流程|真正怎么干|

还需要注意：
一个人回答的内容并不会是实际情况，需要综合多人的内容后，才是真实情况。

### 走一遍业务现场
数字化工作不能只在办公室看系统。因为企业真正的业务是发生在现场的。所以还必须去现场走一遍。

比如生产现场：
- 原材料怎么进来？
- 仓库怎么收货？
- 工单怎么产生？
- 员工怎么领料？
- 生产怎么报工？
- 不良品怎么处理？
- 半成品在哪里？
- 最后怎么入库？

最后可能发现：
- 系统里的流程和现场流程可能完全不是一回事。
### 专业知识分析
在有了相应的事实、证据、问题及根因后，再使用TOGAF，相关的技术架构，如微服务等，进行相应的判断和提议，再给出相应的方案。

### 落地方案评估
与相应的人员评审方案。

## 总结
制造业现状梳理是企业数字化转型的基础工作，其核心不是简单地盘点业务、系统和技术，而是通过全面调研，建立对企业当前经营管理和信息化建设情况的完整认知。
