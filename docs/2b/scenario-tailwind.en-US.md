# Tailwind Development Summary

## Box Model
### Box
- block: Set as block-level element
- box-border: Width and height include padding and border
- box-content: Width and height don't include padding and border, only content width and height

### padding
- p-8: padding: 0.25rem x 8, 2 x 16px = 32px
- pt-6: padding-top
- pr-4: padding-right
- pb-8: padding-bottom
- pl-2: padding-left
- px-8: Left and right padding
- py-8: Top and bottom padding
- ps-8: Content start position padding
- pe-8: Content end position padding
- p-[5px]: Custom spacing
- p-(--my-padding): Use CSS variables

### margin
- m-8: margin: 0.25rem x 8, 2 x 16px = 32px
- mt-6: margin-top
- mb-8: margin-bottom
- ml-2: margin-left
- mr-4: margin-right
- mx-8: Left and right margin
- my-8: Top and bottom margin

- ms-8: Content start position margin
- me-8: Content end position margin

- space-y-4: Top and bottom margin between elements (similar effect to gap, but different implementation. space-x uses margin-right or margin-left control, while gap relies on gap property)
- m-[5px]: Custom spacing
- m-(--my-margin): Use CSS variables
