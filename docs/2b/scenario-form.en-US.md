# Form Development Based on react-hook-form

## Expected Effect
This form page is developed based on shadcn/ui, react-hook-form, and zod. It has the following form field types:
- Plain Text: Only display ordinary text content, such as China
- Input: Ordinary Input input box
- Select: Dropdown type, dropdown values are male and female
- MultiSelect: Multi-select box, options can help set 5 colors
- Checkbox: Selection box, values and labels generated by you, just 6 random ones
- Radio: Radio button, values are Apple, Huawei, xiaomi
- InputNumber: Number type, only fill in numbers
- TextArea: Text box type
- Switch: Switch toggle type
- Email: Email type
- Mobile: Chinese mobile phone number type
- Mobile(Intl): International mobile phone number type for all countries, support selecting area code first, such as +86
- DatePicker: Select date
- DatePicker[showTime]: Select date and time
- MonthPicker: Select year and month
- RangePicker: Select start date and end date
- RangePicker[showTime]: Select start date and time and end date and time
- TimePicker: Select time
- Upload[image]: Upload image type, display uploaded images after upload
- Upload[file]: Upload file type, after upload, display uploaded file list below
- ColorPicker: Color picker
- Rate: 5-star rating effect
- DynamicInput: Has an Add Field button, after clicking, this form field will add an Input input box. When Input input boxes exceed two, there's a delete Icon after Input, can delete an Input
- DynamicInput (Multi): Has an Add Field button, after clicking will add two Inputs, for entering First Name and Last Name. When exceeding two, there's a delete Icon, can delete a row of those two data
- Province, City, District: Display Chinese province, city, district linkage selection
- Checkbox option without label, text display: I have read the agreement

All above form fields are required, label and form field are on the same line.
Default form items have no initial values.
Can click the fill data button below to populate
