# 企业战略解读及架构落地

## 背景
在与制造业的老板交流过程中，经常听他们提起：
- 今年要去越南办厂，且需要尽快投产。
- 中国的制造业现在必须要走出国门。
- 如果只在中国，这个行业未来会越来越难。
- 产品研发的能力必须增强，否则会被淘汰。
- 不能再靠低价竞争了。
- 今年要把营收增加30%
这些话的背后，其实就代表着他们的战略。即：老板想将企业带去哪里？

作为一名IT负责人或架构师，就需要了解：
- 老板为什么这样经营企业
- 企业要靠什么去
- 需要什么样的能力
- 如何组织资源 
- IT/数字化怎么支撑

## 常见的战略类型
不同的战略，对架构会产生不同的影响，常见的有：

| 企业战略  | 主要架构影响                |
| ----- | --------------------- |
| 海外扩张  | 多法人、多语言、多币种、多税制、跨区域部署 |
| 降本    | 成本数据、采购、库存、供应链、精细核算   |
| 提效    | 流程优化、自动化、计划、协同、数据实时性  |
| 提升质量  | QMS、质量追溯、生产数据、SPC     |
| 柔性制造  | APS、工艺、订单配置、产能模型      |
| 扩大产能  | 多工厂架构、产能管理、设备联网       |
| 加强研发  | PLM、BOM、研发流程、版本管理     |
| 做大客户  | CRM、客户协同、订单、质量、交付     |
| 集团化   | 集团主数据、统一标准、财务管控、数据平台  |
| 数字化决策 | 数据平台、指标体系、BI、经营驾驶舱    |

## 如何获取战略信息
### 与老板/董事长聊
对于民营制造企业，真正的战略大理存在于老板的脑子里，所以，首先需要和他们聊：
- 企业为什么要做这个业务？
- 未来三年最想要什么？
- 为什么想做那些？
- 当前最大的风险是什么？

### 与负责经营的人聊
在了解完老板的战略后，还需要看具体的经营情况。老板关注的内容可能会很大，或者是多年后实际的效果，还需要看经营者如何落地。可以交流：
- 今年最关注哪些事情？
- 这些事情怎么变成部门目标？
- 今年哪些目标最重要？
例如：
- 老板：海外市场增长
- 销售：海外订单增长30%
- 生产：交付周期降低20%
- 采购：海外订单物料保障率98%
- IT: 订单、采购、生产数据打通

### 销售/市场负责人
战略落地也不能脱离市场，需要搞清楚市场关注的是哪些因素，可以交流：
- 客户为什么选择我们，而不是竞争对手？
- 客户最在意什么？
从而得出相应的指标，可能是：
```
价格
交期
质量
研发
服务
品牌
稳定性
```

### 生产负责人
战略的问题，最终可能会变成生产系统问题。
- 需要了解公司最影响经营的生产问题是什么？
比如：交期不稳定
- 之后再问为什么
从而发现具体的生产系统问题。

### 其他相关的人
- 财务负责人：了解钱从哪里来？钱花在哪里？哪里赚钱？哪里亏钱？
- 人力负责人：组织能力怎么搭建的
- 企业外部的人：内部的人经常站在自己的公司看问题，外部的人，可以知道行业、市场变化等信息。

## 战略解读：如何把老板的话翻译成架构问题
需要将交流的话翻译成：
- 战略目标
- 业务变化
- 组织变化
- 能力变化
- 流程变化
- 系统/数据/技术变化

## 案例一：海外扩张
### 战略目标
当老板说：
> 未来三年重点发展东南亚市场，并且准备在越南建工厂。
时。这就意味着企业决定进入海外市场。
解读时：并不是海外要部署什么系统。而是要先了解：
> 企业的业务模式、组织方式和经营范围发生了什么变化？
s
### 业务变化
从企业架构角度看，意味着企业从单一中国工厂变成：
```
集团
 ├── 中国
 └── 越南
```
企业的经营范围、组织结构、业务流程和管理方式都发生了变化。

因此，架构师首先应该识别：

- 是否出现新的法人主体？
- 是否出现新的工厂、仓库和销售组织？
- 海外业务是销售为主，还是本地生产？
- 海外工厂与中国总部之间是什么关系？
- 哪些业务由总部统一管理？
- 哪些业务必须由当地组织独立运行？
- 海外业务的规模和发展速度如何？

这些问题的答案，会直接决定后续架构。

### 能力变化
#### 组织能力
- 多法人管理
- 多工厂管理
- 跨组织权限
- 集团与子公司的权责划分

#### 业务能力
- 海外销售
- 海外采购
- 海外生产
- 跨境物流
- 本地仓储
- 本地财务

#### 管理能力
- 集团统一管控
- 海外经营分析
- 全球库存管理
- 全球供应链协同

### 系统变化
- 组织：组织模型变化
- 语言：是否需要i18n能力
- 币种：业务币种，结算币种
- 税务：影响财务模块
- 时间和日期：不同国家使用不同时区，展示时需要变化 
- 部署架构：海外本地部署VS全部部署中国等
- 集团内部工厂贸易：从国内工厂送原材料等到国外工厂。

## 案例二：提效
### 战略目标
需要理解具体的提效目标，需要追问到具体的问题，例如：
- 老板：今年公司的核心战略就是提效。
- 架构师：提高什么效率？
- 老板：订单交付效率。
- 架构师：现在为什么交付慢？

### 业务变化：流程梳理及问题
比如现在的流程梳理发现是：
```
销售接单
 ↓
人工确认交期
 ↓
生产计划
 ↓
采购
 ↓
生产
 ↓
质检
 ↓
入库
 ↓
出货
```

需要确定：
- 哪些步骤现在靠人？
- 哪些步骤可以自动化？
- 哪些步骤需要系统控制？
- 哪些步骤需要数据支撑？

### 系统如何承接
根据问题及现有的系统能力，重新设计流程，或做必要的特色开发。

### 数据分析
根据目标，确定相应的指标。

假设目标是：
> 缩短订单交付周期20%。

那就有要相应的指标，如：
```
订单交付周期
订单准时率
生产等待时间
物料齐套率
计划达成率
设备利用率
```

## 总结
架构师不是把战略翻译成系统，而是把战略翻译成业务能力，再把业务能力落实为流程、组织、系统、数据和技术。
